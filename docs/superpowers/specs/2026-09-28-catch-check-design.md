# 「钓到一条鱼」识别助手 — 设计

## 目标

钓友钓上一条鲑鱼后，在页面上选好地点、认出鱼种、确认脂鳍和体长，页面按当天有效的
DFO 规定告诉他：可以带走（附每日上限）、必须放生，或此处今天禁钓。

结论只来自规定数据。照片只用于在本机和辨认要点对照，不上传、不做 AI 识别。

## 不做

- AI 识图（以后可以作为「预填」层加在上面，不改变判定逻辑）
- 今日渔获计数
- 潮水区（海水）规定
- 硬头鳟、鳟鱼等 BC 省淡水规定

## 入口

- 顶栏按钮「钓到一条鱼」：打开时带上当前选中的河段；没有选中则让用户先选。
- 河段卡片展开后同样的按钮：固定为该河段。

## 面板

手机上为底部抽屉，桌面为右侧面板。自上而下，每项改动后结论立即重算：

1. **地点**：「区域 › 水域 › 河段说明」，可改选；复用目录的区域和河段数据。
2. **照片（可选）**：`<input type="file" accept="image/*" capture="environment">`，
   用 `URL.createObjectURL` 显示，关闭面板时释放；不上传、不存储。
3. **鱼种**：帝王鲑、银鲑、红鲑、粉鲑、狗鲑五张卡片，每张有 SVG 示意图，高亮
   辨认要点；该河段今天有规定的鱼种排前。另有「不是鲑鱼 / 不确定」，给出 BC 省
   淡水钓鱼规定链接，不出结论。
4. **脂鳍**：剪了 / 没剪 / 看不清，配示意图标出脂鳍位置。
5. **体长（厘米，鼻尖到尾叉）**：仅当适用规定涉及体长（最小体长、上限、
   「超过 X cm 最多 N 条」）时显示。

辨认要点（示意图高亮 + 文字）：

| 鱼种 | 要点 |
| --- | --- |
| 帝王鲑 Chinook | 牙龈黑色；尾鳍上下叶都有大斑点；背部斑点大 |
| 银鲑 Coho | 牙龈白色（齿根处）；斑点只在尾鳍上半部；尾柄粗 |
| 红鲑 Sockeye | 无明显斑点；繁殖期体红头绿 |
| 粉鲑 Pink | 尾鳍有大椭圆斑；鳞片极细；繁殖期雄鱼驼背 |
| 狗鲑 Chum | 尾鳍无斑、有银色条纹；繁殖期体侧紫绿竖纹、雄鱼大犬齿 |

## 判定逻辑（`app/catch-check.ts`，纯函数，不依赖界面）

### 规定解析

`parseLimit(regulationEn)` 把可保留规则的英文原文解析为：

```ts
type Limit = {
  daily: number;               // 每日条数
  markedOnly: boolean;         // 只限有孵化场标记
  unmarkedAllowed?: number;    // 「1 of which can be unmarked」
  over?: { cm: number; max: number };  // 超过 cm 的最多 max 条（none over → max 0）
  maxSize?: number;            // 「maximum size 35 cm」「80 cm or less」
};
```

去掉 `FN####` 编号和句末标点后匹配；也识别附带的饵具说明（`bait ban`、
`Fly-fishing only`）作为提醒。解析不了返回 `null`。

最小体长从各区通用说明读取：帝王鲑、红鲑 30 cm，银鲑 25 cm（没有说明的区域用
同样的全省数值）。

### 判定顺序

输入：河段、日期（温哥华时间，复用 `isRuleActive`）、鱼种、脂鳍、体长。

1. 当天有 `species: All` 且 `kind: closed` 的规定 → **此处今天禁钓**。
2. 该鱼种（或 All）当天有 `kind: release` → **必须放生**。
3. 该鱼种当天有 `kind: pending` → **必须放生**（规定待公布）。
4. 当天没有允许保留该鱼种的 `kind: retain` 规定 → **必须放生**（今天不允许保留）。
5. 有 `retain` 规定但 `parseLimit` 返回 `null` → **请按原文判断**。
6. 只限有标记（且无 `unmarkedAllowed`）而脂鳍为「没剪」或「看不清」→ **必须放生**。
   有 `unmarkedAllowed` 时，「没剪」可以带走，但要注明无标记最多几条。
7. 体长低于最小体长、超过 `maxSize`，或 `over.max === 0` 且超过 `over.cm`
   → **必须放生**。
8. 其余 → **可以带走**，附上限说明，例如「每日最多 4 条，其中超过 50 cm 的最多
   2 条」，并提示所有鲑鱼合计每日不超过 4 条、请自行核对今天已带走的数量。

需要体长但尚未填写时，结论显示「请填写体长」而不是猜测。

`kind: gear` 的规定不影响结论，作为提醒一并显示。

## 结论区

- 大号色块：绿色可带走、橙色必须放生、红色禁钓、灰色请按原文判断 / 信息不全。
- 列出据以判定的 DFO 原文、日期范围、原文链接。
- 固定免责：「仅供参考，以 DFO 公告和现场标志为准；认不准鱼种或标记时请放生。」
- 中英双语，跟随页面语言。

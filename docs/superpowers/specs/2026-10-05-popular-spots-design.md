# 第 2 区常去钓点 — 设计

## 目标

在第 2 区（低陆平原）每条已画出红线的河上，标出钓友常去的具体位置（水潭、砾石滩、
岸边入口），并告诉读者怎么去、消息来自哪里、这段今天的 DFO 规定是什么。

## 不做

- 第 2 区以外的区域（确认效果后另起一轮）
- 评分、实时渔情、用户投稿
- 自动抓取 Facebook、TikTok、小红书：这些平台要登录才能看到内容。只用搜索引擎
  收录的公开帖子和视频，以及用户手动提供的链接或截图。

## 数据来源与收录标准

- 来源：公开论坛与渔情报告、渔具店和向导的博客、公开视频（YouTube 等）、
  OpenStreetMap 的 `leisure=fishing` 标记、用户提供的内容。
- 收录条件：至少两个互相独立的来源提到同一个钓点；或者一个来源，加上能在卫星
  影像或 OSM 上对上的具体地物（桥、停车场、汇流口、命名的水潭）。只有模糊说法
  （如「Vedder 下游某处」）的不收。
- 每个来源记录标题、链接、类型（forum / report / blog / video / osm / social /
  user）和查阅日期。

## 不收的位置

- 落在常年禁钓范围内的：政府孵化、计数、过鱼设施 100 米以内（第 2 区通用规定），
  以及表格写明全年禁钓的段落。只在部分季节禁钓的段落照常收录，弹窗按当天规定
  显示禁钓。
- 私人土地、需要穿越铁路或私人地块才能到达的位置。

## 与规定的关系

来源里关于「能不能钓、能带走几条」的说法一律不采用。钓点只挂在一个 DFO 河段上，
弹窗显示的今天状态和限额完全来自该河段的规定数据，与河段卡片一致。

## 数据结构

新文件 `app/popular-spots.ts`，手工维护：

```ts
type SpotSource = {
  title: string;
  url: string;
  kind: "forum" | "report" | "blog" | "video" | "osm" | "social" | "user";
  accessed: string; // YYYY-MM-DD
};

type PopularSpot = {
  id: string;
  reach: string;                 // region2Spots 的 id，如 "chilliwack-vedder"
  name: LocalizedText;
  coordinates: [number, number];
  kind: "pool" | "bar" | "access" | "bank";
  species?: Species[];           // 来源中提到的目标鱼种
  months?: number[];             // 来源中提到的常去月份
  access: LocalizedText;         // 停车、步行
  sources: SpotSource[];
};
```

## 界面

- 地图：钓点用与规定端点不同的小图标；图层控件里可开关「常去钓点」，默认开。
- 点击钓点：名称、类型、怎么去、来源链接列表、「这段今天的规定」（状态与所属河段
  一致），点它展开对应河段卡片。
- 河段卡片：列出该河段的钓点，点名字地图飞到该点。
- 双语；钓点名称保留常用英文叫法，中文附说明。

## 测试

- 每个钓点至少一个带 `https` 链接的来源；编号唯一；所属河段存在于第 2 区。
- 坐标在第 2 区范围内，且离所属河段红线不超过 150 米（`access` 类型放宽到 400 米）。
- 不在已知孵化、计数设施 150 米以内。
- 页面渲染测试：开启图层后地图上有钓点，弹窗显示所属河段的今天状态。

## 流程

逐条河搜集整理 → 在本地网页上由用户逐个检查 → 确认后提交推送。
